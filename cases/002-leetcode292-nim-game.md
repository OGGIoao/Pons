## 场景

你和对手轮流从一堆 n 颗石子中取 1~3 颗，拿到最后一颗者获胜。这是面试里最经典的博弈论入门题，也是"回合制完全信息游戏"的最小形态——桌游设计、抢 30 报数游戏、轮流取火柴的酒吧游戏，全是它的换皮。

## 信号

出现这些特征就该往必胜/必败态上想：双方完全信息、每步选择有限、规则固定、目标是"让对手无路可走"。小规模先手算几步：能一步走进必败态的位置就是必胜态——逆推的起点是终局。

## 桥接

从终局倒推：n=0 是必败态（轮到你没的拿）；n=1,2,3 可一步到 0 → 必胜；n=4 无论拿几都留给对手 1~3 → 必败；n=5,6,7 可一步到 4 → 必胜……周期 4 赫然浮现。结论一句话：n 是 4 的倍数先手必败，否则必胜——"把对手逼进模 4 余 0 的坑"就是全部策略。

## 解答

```python
def can_win_nim(n: int) -> bool:
    # 必败态：轮到谁谁输。n=1,2,3 时一手拿光（必胜）；
    # n=4 时无论拿几都给对手留下 1~3（必败）——按 4 的倍数归纳。
    return n % 4 != 0

assert can_win_nim(4) is False
assert can_win_nim(1) and can_win_nim(2) and can_win_nim(7)
print("Nim：n=4 必败，其余小值必胜")
```
