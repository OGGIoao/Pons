## 场景

草药老师傅带你去采药：总时间只有 T 秒，山上有 M 株草药，每株要花时间、有价值，每株最多采一次。问在规定时间内能采到的最大总价值——这是 OI 界公认的 01 背包模板题，无数选手的 DP 启蒙。

## 信号

"总量有限（时间/重量/预算），每个物品最多选一个，最大化总价值"——三要素齐了就是 01 背包。识别口诀：拿还是不拿？拿→容量减 w_i、价值加 v_i；不拿→什么都不变。两个分支取 max，就是最优子结构。

## 桥接

dp[c] = 容量 c 时的最大价值。关键只有一个：容量循环**倒序**——保证第 i 株草药在本周期的 dp[c-w] 里还没被用过，即"每株最多一次"。正序写就完全背包了（这是 006 卡片的故事）。倒序、max、滚动数组，三件套背下来，所有资源分配题换皮不换骨。

## 解答

```python
def best_herbs(t: int, herbs: list) -> int:
    """每株草药最多采一次：容量维度**倒序**更新（01 背包）。"""
    dp = [0] * (t + 1)
    for cost, val in herbs:
        for c in range(t, cost - 1, -1):
            dp[c] = max(dp[c], dp[c - cost] + val)
    return dp[t]

assert best_herbs(70, [(71, 100), (69, 1), (1, 2)]) == 3   # 洛谷 P1048 官方样例
print("P1048 采药样例：70 时间最优值 = 3")
```
