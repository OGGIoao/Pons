## 场景

还是那座山，但这次草药管够——同一株可以反复采，直到时间用完。同样的输入数据，P1048 采药的最优值是 3，这题的最优值却是 140：选"1 秒、价值 2"的那株采 70 次。一字之差（每株限采一次 vs 不限），模型从 01 背包变成完全背包。

## 信号

"不限量"、"可以重复选"、"每种物品任意多个"——完全背包的信号。它和 01 背包长得一模一样，唯一区别就在容量循环方向：正序允许同一物品在同一轮被反复取用。两张卡片（005 和 006）放在一起就是为了治"方向写反"这个最高发错误。

## 桥接

代码和 01 背包只有一行之差：`for c in range(cost, t+1)`（正序）替换 `range(t, cost-1, -1)`（倒序）。正序时 dp[c-cost] 已经是**本轮**更新过的值，等于"已经采过这株、再采一次"——无限量语义自然涌现。理解了这一行，就完全理解了滚动数组的本质。

## 解答

```python
def best_herbs_unbounded(t: int, herbs: list) -> int:
    """每株草药可无限采：容量维度**正序**更新（完全背包）——同一行可重复取用。"""
    dp = [0] * (t + 1)
    for cost, val in herbs:
        for c in range(cost, t + 1):
            dp[c] = max(dp[c], dp[c - cost] + val)
    return dp[t]

assert best_herbs_unbounded(70, [(71, 100), (69, 1), (1, 2)]) == 140  # P1616 样例
print("P1616 疯狂采药：正序更新后同一样例从 3 变 140")
```
