## 🚩 阶段一：挑战

> **只看这个阶段，自己想 10 分钟。不要往下翻。**

### 场景：星际基地排期

你是"火星殖民计划"的项目经理。基地建设有 4 个阶段：

| 阶段 | 代号 | 说明 |
|------|------|------|
| 发射前准备 | A | 第一天 = 第 0 天 |
| 轨道组装 | B | **至少比 A 晚 5 天**开始 |
| 燃料补给 | C | **至少比 A 晚 3 天**开始 |
| 火星着陆 | D | **至少比 B 晚 4 天**，且**至少比 C 晚 2 天**开始 |

依赖关系翻译成人话：

```
B ≥ A + 5
C ≥ A + 3
D ≥ B + 4
D ≥ C + 2
```

但还有一条约束——总工程师说：**"从 A 到 D 最多 15 天。"**

```
D ≤ A + 15
```

### 要你回答

在满足所有条件的前提下：

1. **最快**第几天能到 D？（最短工期）
2. **最晚**可以拖到第几天？（D 的最晚上限）

> 不要用直觉猜。把 5 个约束写成数学不等式，找一种**系统性的方法**求解。
>
> 关键观察：每一条依赖关系都能写成**同一种统一形式**的不等式。

> 💬 *先别往下翻。把 5 个约束写成不等式，尝试手算出 A、B、C、D 的范围。如果你能先想到"最快 = 9 天"，说明你的直觉是对的——但接下来要回答的是"为什么能系统性地算出来"。*

**提示 1：统一每一种约束的形式**

"至少"约束是 `B ≥ A + 5`。能不能把它写成 **`某变量 − 某变量 ≤ 常数`** 的形式？

```
B ≥ A + 5   →   A − B ≤ −5
```

对。全部这样写：

| 原文 | 不等式 | 统一形式 `xⱼ − xᵢ ≤ c` |
|------|--------|------------------------|
| B ≥ A + 5 | B − A ≥ 5 | **A − B ≤ −5** |
| C ≥ A + 3 | C − A ≥ 3 | **A − C ≤ −3** |
| D ≥ B + 4 | D − B ≥ 4 | **B − D ≤ −4** |
| D ≥ C + 2 | D − C ≥ 2 | **C − D ≤ −2** |
| D ≤ A + 15 | D − A ≤ 15 | **D − A ≤ 15** |

> 现在 5 条约束长得一模一样了——每条都是"某个变量减去另一个变量 ≤ 某个常数"。

**提示 2：把「统一形式」画成图**

`xⱼ − xᵢ ≤ c` 意味着 `xⱼ ≤ xᵢ + c`。

换句话说——**从 i 到 j 有一条边，走过去最多加 c**：

```
xᵢ ——(权重 c)——→ xⱼ
```

把提示 1 的 5 条不等式全部画成「节点 + 有向边 + 权重」。

**提示 3：路径的累加 = 约束的复合**

如果你有两条边：

```
A ——(3)——→ B ——(1)——→ C
```

那就意味着 `C ≤ A + (3 + 1)`。**沿一条路径走，把权重加起来，就是把一路上所有约束复合起来。**

问题来了：从 A 到 D 可能有**多条路径**，每条路径都给出一个"≤ 上界"。多个上界同时成立时，你该信哪一个？

```
A —→ D           权重 15    → D ≤ A + 15
A —→ B —→ D      权重 ?     → D ≤ A + ?
A —→ C —→ D      权重 ?     → D ≤ A + ?
```

**提示 4：最紧的上界 = 最短路；矛盾 = 负环**

- 多条路径给出多个上界 `D ≤ A + w₁`、`D ≤ A + w₂`……，**最紧的那条（w 最小的那条）才是真正的上限**。所以「最晚能到几号」就是**最短路**。
- 如果沿着某条环路走一圈，权重之和是**负数**——说明约束自相矛盾（绕一圈回来要求 `xᵢ ≤ xᵢ + 负数`，即 `xᵢ < xᵢ`）。**负环 = 无解**。

> 💬 *现在你应该知道方向了：把不等式画成图，用"最短路"回答"最晚"，用"最长路"（关键路径）回答"最快"。去阶段三，把思路翻译成代码。*

### 核心洞察

> **把"不等式"翻译成"图"，把"求解"翻译成"最短路"。**

三个要点：

**① 统一形式**——所有约束都能写成 `xⱼ − xᵢ ≤ c`（`xⱼ ≤ xᵢ + c`）。哪怕原本是 `≥`，两边乘 −1 移项也能归一到这个形式。

**② 翻译成图**——`xⱼ − xᵢ ≤ c` 就是一条边 `i → j`，权重 `c`，语义是"从 i 走到 j，最多增加 c"。

**③ 求解 = 最短路**——从源点跑到每个节点的最短距离 `dist[j]`，就是 `xⱼ` 能取到的**最大值（最晚上限）**；如果存在**负环**，说明约束自相矛盾，**无解**。

还有一对对偶关系，记住它就不会迷路：

| 想求什么 | 用什么 | 本卡片里的含义 |
|---------|--------|---------------|
| **最大值 / 最晚**（上界 `xⱼ ≤ …`） | **最短路** | 最晚第几天到 D |
| **最小值 / 最快**（下界 `xⱼ ≥ …`） | **最长路**（关键路径） | 最快第几天到 D |

### 三步翻译——自己写代码

现在你已经知道"最短路"这个方向了。**在翻到阶段四之前，自己写出代码。**

**第一步：说清意图**

```
把一组 xⱼ − xᵢ ≤ c 约束建成图，用 Bellman-Ford 求最短距离。
因为边权有负数（≥ 约束会变成负权），不能用 Dijkstra。
```

**第二步：拆成标准操作**

```
→ 建边：每条约束 (i, j, c) 生成有向边 i→j，权重 c
→ 初始化 dist[源点] = 0，其余 = ∞
→ 松弛 n−1 轮：每条边 u→v，若 dist[u]+w < dist[v] 则更新
→ 第 n 轮再试：若还能更新 → 存在负环 → 无解
→ 返回 dist（每个变量的最晚上限）
```

**第三步：匹配到代码**

| 标准操作 | 代码实现 |
|---------|---------|
| 边列表 | `edges = [(u, v, w), ...]` |
| 初始化距离 | `dist = [INF] * n; dist[src] = 0` |
| 松弛 | `if dist[u] + w < dist[v]: dist[v] = dist[u] + w` |
| 负环检测 | 第 n 轮再更新一次，若发生则 `return None` |

### 参考实现

**核心算法：Bellman-Ford（处理负权边的单源最短路）**

```python
def bellman_ford(n: int, edges: list[tuple[int, int, int]], src: int):
    """
    单源最短路（允许负权边，用于差分约束）。

    edges: [(u, v, w)] 表示存在约束 x_v - x_u <= w，即边 u→v 权重 w。
    返回 dist 列表；若存在负环（约束无解）返回 None。
    """
    INF = float('inf')
    dist = [INF] * n
    dist[src] = 0

    # 松弛 n-1 轮
    for _ in range(n - 1):
        changed = False
        for u, v, w in edges:
            if dist[u] != INF and dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                changed = True
        if not changed:          # 提前收敛，可跳出
            break

    # 第 n 轮：还能更新 → 负环 → 无解
    for u, v, w in edges:
        if dist[u] != INF and dist[u] + w < dist[v]:
            return None

    return dist
```

**应用：求解星际基地排期**

```python
# 变量编号：A=0, B=1, C=2, D=3
# 统一形式 x_j - x_i <= c  →  边 i→j 权重 c
#   B >= A+5  →  A - B <= -5  →  边 B→A 权重 -5
#   C >= A+3  →  A - C <= -3  →  边 C→A 权重 -3
#   D >= B+4  →  B - D <= -4  →  边 D→B 权重 -4
#   D >= C+2  →  C - D <= -2  →  边 D→C 权重 -2
#   D <= A+15 →  D - A <= 15  →  边 A→D 权重 15
edges = [
    (1, 0, -5),   # B→A
    (2, 0, -3),   # C→A
    (3, 1, -4),   # D→B
    (3, 2, -2),   # D→C
    (0, 3, 15),   # A→D
]

# 从 A 出发求最短路 → 得到每个里程碑的"最晚"上限
dist = bellman_ford(4, edges, src=0)
name = ['A', 'B', 'C', 'D']
for i in range(4):
    print(f"{name[i]} 最晚 ≤ 第 {dist[i]} 天")

# 输出：
#   A 最晚 ≤ 第 0 天
#   B 最晚 ≤ 第 11 天
#   C 最晚 ≤ 第 13 天
#   D 最晚 ≤ 第 15 天   ← 回答"最晚第 15 天"
```

**回答"最快第几天"——最长路（关键路径）**

"最快"是下界（`xⱼ ≥ xᵢ + d`），需要**最长路**。这个依赖图恰好是 DAG，直接按拓扑序取最大值即可：

```python
# ≥ 约束：A→B(5), A→C(3), B→D(4), C→D(2)
ge_edges = [(0, 1, 5), (0, 2, 3), (1, 3, 4), (2, 3, 2)]
dist = [0, 0, 0, 0]      # 最早都从第 0 天开始
for u, v, w in ge_edges:  # 拓扑序恰好就是 (A, B, C, D)
    dist[v] = max(dist[v], dist[u] + w)
print(f"D 最快 ≥ 第 {dist[3]} 天")   # → D 最快 ≥ 第 9 天
```

所以答案：**最快第 9 天，最晚第 15 天**。

### 深度思考——为什么"最短路"和"最长路"是一对

差分约束的威力在于它统一了两种看起来相反的"方向"：

- 一堆 `xⱼ ≤ xᵢ + c`（上界）问"最多能到哪" → **最短路**取最紧的上界
- 一堆 `xⱼ ≥ xᵢ + d`（下界）问"最早从哪开始" → **最长路**取最紧的下界

它们是**对偶**的：把不等式两边乘 −1，"最短路"就变成"最长路"。工程排期里的**关键路径法（PERT/CPM）**其实就是最长路——和差分约束是同一枚硬币的两面。

### 这个模式还出现在……

| 领域 | 问题 | 对应关系 |
|------|------|---------|
| **工程排期 / 项目管理** | 求最短工期、找关键路径 | 下界约束 → 最长路（CPM） |
| **约束满足 / 资源分配** | 一堆"不早于/不晚于"找可行排班 | 差分约束 + Bellman-Ford |
| **静态分析 / 类型系统** | 变量取值范围传播（值域分析） | 上界下界在图上传播 |
| **调度算法** | 任务有先后 + 期限，判定是否可行 | 负环检测 = 检测死锁/矛盾 |
| **编译器** | 寄存器分配、指令调度中的时序约束 | 同一套图论翻译 |
